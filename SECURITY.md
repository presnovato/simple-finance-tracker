# Безопасность

Finance Tracker работает с чувствительными финансовыми данными. Это личный
owner-only проект, поэтому перед публичным развёртыванием проверь переменные
окружения, Telegram `initData`, домен TMA и постоянный volume SQLite.

Не публикуй в issue или pull request:

- `BOT_TOKEN`, `OPENROUTER_API_KEY` и другие секреты;
- реальные чеки, выписки, операции и содержимое базы;
- production-логи с персональными данными.

О потенциальной уязвимости сообщай приватно через GitHub Security Advisories
репозитория. Для обычных ошибок используй issue без секретов и приложи
минимальный воспроизводимый пример.
