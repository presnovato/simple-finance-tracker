# Безопасность

Finance Tracker работает с чувствительными финансовыми данными. Это личный
owner-only проект, поэтому перед публичным развёртыванием проверь переменные
окружения, Telegram `initData`, домен TMA и постоянный volume SQLite.

Не публикуй в issue или pull request:

- `BOT_TOKEN`, `OPENROUTER_API_KEY` и другие секреты;
- реальные чеки, выписки, операции и содержимое базы;
- production-логи с персональными данными.

О потенциальной уязвимости сообщай приватно через GitHub Security Advisories
репозитория. Для обычных ошибок используй issue без секретов и приложи
минимальный воспроизводимый пример.

## Что уходит на серверы при AI-захвате

При включённом `OPENROUTER_API_KEY` на сторонний сервис OpenRouter отправляются:

- фото чека или скриншота (base64), PDF-файл или текст сообщения;
- текущая дата (`effective_today()`), чтобы модель не поставила будущую дату;
- список допустимых категорий и инструкции промпта.

Не отправляются: база данных, суммы прошлых операций, имя владельца, `initData`.

По умолчанию запрос идёт с `provider.data_collection = "deny"` — OpenRouter
исключает провайдеров, которые хранят данные и могут обучаться на них. Выключается
через `LLM_DENY_DATA_COLLECTION=0` (тогда провайдеры выбираются свободно).
Если у модели нет провайдеров без сбора данных, запрос завершится ошибкой —
бот сообщит «ИИ сейчас недоступен» и сохранит черновик.

Файлы больше 20 МБ (лимит Bot API `getFile`) не скачиваются и не отправляются.
